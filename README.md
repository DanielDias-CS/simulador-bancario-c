# Simulador Bancário em C

## Sobre o projeto
Este projeto consiste em um simulador bancário desenvolvido em linguagem C durante minha formação em Ciência da Computação.

O programa permite simular operações bancárias básicas por meio de um menu interativo.

## Funcionalidades
- Depósito de valores.
- Saque com verificação de saldo.
- Transferências simuladas via PIX, DOC e TED.
- Consulta de saldo.
- Registro de transações em arquivo de texto (`extrato.txt`).
- Validação de entradas e valores.

## Tecnologias utilizadas
- Linguagem C.
- Funções e ponteiros.
- Estruturas condicionais e de repetição.
- Manipulação de arquivos.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Compile o programa utilizando o GCC:

   gcc main.c -o simulador

4. Execute o programa:

   ./simulador

## Objetivo
Praticar conceitos fundamentais da programação em C, desenvolvendo um programa com diferentes operações, validação de dados e registro de transações.

## Observação
Este projeto tem finalidade exclusivamente educacional. As operações são simuladas e não envolvem transações financeiras reais.
